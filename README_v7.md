# Biz-DNA v7.0 — 소상공인 경영개선 실행·성과추적 MVP

기존 v6.0 기능(자가진단, 업종별 진단, DNA 유형, PDF, 상권 집계, SQLite 저장)에 다음을 추가했습니다.

- `followup.py`: 실행과제 등록, 담당자/목표일, 상태변경(계획/진행/완료/보류)
- 후속 월별 매출/비용/재방문율 입력, 최초 진단 대비 매출 증감률과 단순 영업잔여액 산출
- Streamlit 메뉴 `개선과제·성과추적`, 그래프, JSON 내보내기
- SQLite 외래키 ON 및 진단 삭제 시 연결된 실행과제/측정값 연쇄 삭제
- `test_v7.py`: 성과산식, 상태관리, 데이터 검증, 삭제 검증

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 테스트
```bash
python test_v6.py
python test_v7.py
```

## 제한
- 로컬 시연용입니다. 로그인, 권한관리, 암호화, 운영기관 분리, 개인정보 처리체계가 없습니다. 실제 개인정보나 영업기밀 입력 및 공개 배포 금지.
- 월별 매출-비용은 회계상 영업이익과 일치하지 않을 수 있습니다.
- 매출 전후 비교는 계절성/물가/상권 변화 등을 통제하지 않으므로 개선과제의 인과효과가 아닙니다.
- 후속 실적은 수기입력 방식이며 실제 카드매출·상권 DB 연계 및 AI 자동 서술은 미구현입니다.
- 추천 가중치와 진단점수는 실증 검증 전 가설모형입니다.
