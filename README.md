# Biz-DNA v6.0 — 소상공인·상권 운영기관용 시범 플랫폼

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 구현
- 기존 v5 진단모형(16 DNA 문항, 32 역량문항, 업종별 12문항 선택, 잠정 성장단계, 위험신호, 전략추천, PDF) 재사용
- 점주용 Streamlit 설문 및 진단결과, 기본/정밀 PDF
- 저장 동의 시 SQLite 진단이력 저장, 이력 열람·개별 삭제·JSON 내보내기
- 상권·업종별 점포 단위 최신 진단만 집계(중복점포의 재진단 과대집계 방지)
- 5개 점포 미만 집계 비공개, 영역별 평균·유형분포·전략수요 그래프

## 필수 주의사항
**개발·시연 전용**: 인증·사용자별 권한관리·DB 암호화·운영서버 보안·백업·접근로그·동의 철회 워크플로우 미구현. 인터넷에 공개하거나 실제 개인정보·영업기밀을 입력하지 마세요. 같은 상권 내 같은 점포명은 같은 점포로 묶는 시범용 키이므로 실운영에서는 별도 사업자 식별키와 개인정보 분리 저장이 필요합니다. DB는 `bizdna_demo.sqlite3`; `BIZDNA_DB` 환경변수로 경로 변경 가능.

실제 카드매출·상권 DB 연계 및 생성형 AI 심층보고서 자동 작성은 이 버전에 포함되지 않습니다. PDF는 기존 규칙기반 자동생성입니다. 진단 가중치·임계값·전략규칙은 실증 검증 전 가설모형이며, 통계는 자발적 참여점포의 기술통계일 뿐 상권 전체를 대표하지 않습니다.
